# 🌐 RutaU_Vanilla_JS | Módulo de JavaScript Puro (Vanilla ES6+)

Implementación de la lógica de negocio y controladores del proyecto **RutaU** utilizando exclusivamente **JavaScript nativo (Vanilla ES6+)** sin frameworks.

---

## 🚀 Características del Código Vanilla JS

- **Gestión de Estado Nativa:** Estado reactivo con patrones de eventos y persistencia en LocalStorage.
- **Controladores del DOM:** Manipulación de interfaces, modales, filtros dinámicos y consumo de APIs sin librerías externas.
- **Consumo de Supabase:** Integración con el cliente Supabase JS para autenticación y base de datos.
- **Sin HTMLs Duplicados:** Todo el código reside en `app.js` listo para ser importado o analizado como implementación pura de JavaScript.

---

## 📂 Archivos del Módulo

- `app.js`: Código fuente en JavaScript Vanilla con todas las funciones de autenticación, reservas, cartelera nocturna y validaciones universitarias.
- `README.md`: Documentación de la implementación Vanilla JS.
