# 📚 RutaU | Documentación Integral y Especificación Técnica

**RutaU** es la Red Universitaria de Movilidad Segura y Solidaria desarrollada para la **Institución Universitaria Pascual Bravo** (Medellín, Colombia), enfocada en solucionar la problemática de transporte nocturno para estudiantes, docentes y personal institucional.

---

## 🎯 Objetivo General
Conectar a miembros verificados de la comunidad académica del Pascual Bravo que comparten rutas similares en horarios nocturnos (salidas entre 21:00 y 22:30 hrs), optimizando costos de transporte mediante aportes justos a la gasolina, reduciendo la huella de carbono y brindando un entorno de viaje seguro y monitoreado.
